## Projects

### At Corbits

- **[Corbits Triage](https://github.com/corbitsdev/corbits-triage)** — Triage pull requests against your contribution policy.
- **[Workbench](https://github.com/corbitsdev/workbench)** — Multiplayer workspace for humans and agents built on Corbits.
- **[Solution Builder](https://github.com/corbitsdev/corbits-solution-builder)** — Hone problem statements, generate complete solutions, get stakeholder buy-in, and build the application.
- **[Interchange](https://github.com/faremeter/interchange)** — An agentic operating system. The `@intx/agent` runtime with packaged tools, embedding, and a multi-tenant stack.
- **[Corbits Code](https://github.com/corbitsdev/corbits-code)** — Open-source coding agent TUI with flexible agent loops and smart compaction.

### Applied AI

- **[WebMCP](https://github.com/TheGreatAxios/webmcp)** — Framework-agnostic WebMCP implementation. Three NPM packages: model contexts, React bindings, and a desktop-agent bridge.
- **[Faraday](https://github.com/TheGreatAxios/faraday)** — Agent-native 3D medical scan reading room. Won the OpenAI WebMCP Challenge. Voxels never leave the browser.
- **[ai-sdk-privacy-filter-middleware](https://github.com/TheGreatAxios/ai-sdk-privacy-filter-middleware)** — Vercel AI SDK middleware that redacts PII locally using Transformers.js. No API calls.
- **[privacy-filter-python](https://github.com/TheGreatAxios/privacy-filter-python)** — Local-first PII detection and reversible redaction for NanoBot and OpenAI Agents SDK.
- **[privacy-python-server](https://github.com/TheGreatAxios/privacy-python-server)** — Privacy-first AI server with offline PII redaction.
- **[video-transcription-modal](https://github.com/thegreataxios/video-transcription-modal)** — CPU-optimized transcription on Modal using faster-whisper with INT8 quantization.
